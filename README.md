# Sparkling Clean

A responsive website for a home-cleaning service, built with React and Vite.

## Services

- House cleaning
- Oven cleaning
- Window cleaning
- Carpet cleaning

## Features

- Responsive, mobile-friendly layout
- Reusable React components
- Custom SVG logo and favicon
- Quote request form
- Netlify Forms integration with spam protection

## Tech stack

- React
- Vite
- CSS
- Netlify Forms

## Run locally

```bash
npm install
npm run dev
```
